# Customs Data Reference

## What to verify
1. Importer identity
2. Product description
3. HS code when available
4. Origin country
5. Shipment date
6. Quantity/weight
7. Port or destination when available
8. Supplier/exporter name when available
9. Frequency and recency

## Interpretation rules
- A shipment proves movement, not necessarily current purchasing.
- One shipment does not prove annual volume.
- Product descriptions can be broad; map them to specifications before calling them a Shen Heng match.
- HS codes are useful but not sufficient on their own because one code can contain multiple products.
- Different trade-data platforms may have different coverage. Treat discrepancies as data-coverage differences until reconciled.

## Commercial use
Prioritize repeated recent shipments, relevant products, China-origin shipments, and identifiable suppliers. For customer-development lists, record the evidence date so old import activity is not presented as current demand.
