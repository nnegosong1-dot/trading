# Add Research Fields

## Trigger
`/research-add-fields <fields or dimension>`

## Workflow
1. Locate the active `<topic_slug>/fields.yaml`.
2. Review existing categories and definitions.
3. Identify missing fields that materially improve the user's decision.
4. Avoid redundant fields.
5. Preserve the existing detail-level conventions and uncertainty mechanism.
6. Update `fields.yaml` and explain the additions.

## Default Shen Heng additions when relevant
- HS code and exact product description
- Import quantity/value/unit value and data year
- China import share
- Major origin countries
- Importer name and importer frequency
- Supplier name and supplier origin
- Product specifications / dimensions / grade
- Anti-dumping / safeguard / tariff status
- Effective date and product scope of trade measures
- Website evidence of demand
- Contact person / role / email / phone / WhatsApp / LinkedIn
- Evidence strength and verification date
- Duplicate status
- Commercial attractiveness score and reason
